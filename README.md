### Desarrollador Backend con enfoque Fullstack | Java & Spring Boot

Soy estudiante de programación y desarrollador en formación, con más de un año y medio de aprendizaje continuo en desarrollo de software. Mi principal interés está en el **backend**, especialmente en el diseño de lógica de negocio, manejo de datos y construcción de aplicaciones robustas y mantenibles, aunque también cuento con experiencia trabajando el **frontend** para desarrollar soluciones completas.

Más recientemente finalicé una especialización en **Desarrollo de Aplicaciones Web**, donde trabajé con **Java, Spring Boot y MySQL**, integrando frontend con **HTML, CSS y JavaScript**, y utilizando herramientas como **Git, GitHub, Postman, Lombok, Bootstrap y Thymeleaf**.

Actualmente estudio **Ingeniería en Informática en la UBA**, con el objetivo de seguir fortaleciendo mi base académica y técnica.

Proyecto desarrollado en **Java**, enfocado en la aplicación de **Programación Orientada a Objetos**. Modela el funcionamiento de una concesionaria mediante clases, herencia, clases abstractas e interfaces, priorizando una estructura clara y una lógica de negocio coherente.

### 🍽️ Proyecto Gestión de Pedidos Gastronómico

<a href="https://github.com/TomasMascotena/Proyecto-Gestion-de-Pedidos-Gastronomico">
  <img src="https://raw.githubusercontent.com/TomasMascotena/Proyecto-Gestion-de-Pedidos-Gastronomico/main/assets/preview2.png" width="700"/>
</a>

Sistema de gestión de pedidos para un entorno gastronómico, desarrollado como aplicación **web fullstack**, con foco en el **backend**. Permite administrar pedidos, productos y relaciones entre entidades, simulando un escenario real de negocio.

**Tecnologías y conceptos aplicados:**
- Java + Spring Boot  
- MySQL  
- Arquitectura por capas  
- Lógica de negocio y persistencia de datos  
- Integración frontend con HTML, CSS, JavaScript, Bootstrap y Thymeleaf  
- Consumo y prueba de endpoints con Postman
